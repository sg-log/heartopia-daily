# Weather icon templates

These cropped game weather icons are used by the browser-only screenshot parser.

- `sun-day.png` -> `晴`
- `sun-night-slot0.png` -> `晴`
- `sun-night-slot1.png` -> `晴`
- `sun-night-slot4.png` -> `晴`
- `heatwave.png` -> `猛暑`
- `rainbow.png` -> `虹`
- `meteor-shower.png` -> `流星群`
- `rain.png` -> `雨`

Snow and cherry blossom templates are intentionally absent until real source screenshots are available.
